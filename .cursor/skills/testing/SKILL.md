# Testing

Read `docs/TESTING.md`, `docs/ACCESSIBILITY.md`.

- Prefer behavior tests with accessible names
- Cover scoring, invite validation, and API auth when those modules exist
- Coverage goal ≥80% on tested `lib/` modules as Phase 1 grows
- Do not delete tests to greenwash coverage
- Run `make test` (and `make test-coverage` when relevant)
